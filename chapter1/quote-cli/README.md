# quote-cli

무작위 명언을 출력하거나 전체 명언 목록을 보여주는 간단한 Java 명령줄 도구입니다.
외부 라이브러리 없이 JDK만으로 동작합니다.

## 프로젝트 구조

```
quote-cli/
├── Quote.java        # 메인 프로그램
├── QuoteTest.java    # 테스트
├── quotes.json       # 명언 데이터 (문자열 배열)
├── README.md
└── prompt/           # 작업에 사용한 프롬프트 기록
```

## 설치 방법

### 요구 사항

- **JDK 14 이상** (단일 파일 소스 실행, `Path.of`, `switch` 화살표 문법 사용). JDK 11~13에서는 컴파일되지 않습니다.

설치 여부는 아래 명령으로 확인합니다.

```bash
java -version
```

JDK가 없다면 Windows에서는 다음과 같이 설치할 수 있습니다.

```powershell
winget install EclipseAdoptium.Temurin.21.JDK
```

### 프로젝트 받기

별도의 빌드나 의존성 설치는 필요 없습니다. 이 디렉터리를 내려받기만 하면 됩니다.

```bash
cd quote-cli
```

> `quotes.json`을 현재 디렉터리에서 읽으므로 반드시 `quote-cli` 디렉터리에서 실행하세요.

## 실행 예시

인수 없이 실행하면 무작위 명언 하나를 출력합니다.

```bash
java Quote.java
```

```
오늘 할 수 있는 일을 내일로 미루지 마라. - 벤저민 프랭클린
```

`--list`(또는 `-list`)를 주면 전체 목록을 번호와 함께 출력합니다.

```bash
java Quote.java --list
```

```
1. 배움에는 왕도가 없다. - 유클리드
2. 천 리 길도 한 걸음부터. - 노자
3. 오늘 할 수 있는 일을 내일로 미루지 마라. - 벤저민 프랭클린
4. 실패는 성공의 어머니다. - 토머스 에디슨
5. 가장 큰 위험은 아무런 위험도 감수하지 않는 것이다. - 마크 저커버그
6. 시작이 반이다. - 아리스토텔레스
7. 행동은 모든 성공의 기초가 되는 열쇠다. - 파블로 피카소
```

## 명언 추가하기

`quotes.json`에 문자열을 추가하면 됩니다.

```json
[
  "배움에는 왕도가 없다. - 유클리드",
  "새로운 명언 - 작성자"
]
```

## 테스트 실행

```bash
java QuoteTest.java
```

다음을 검증하며, 모두 통과하면 종료 코드 0, 하나라도 실패하면 1로 끝납니다.

- 인수 없이 실행하면 명언이 한 줄만 출력되고, 그 명언이 `quotes.json`에 존재하는지
- `--list` / `-list` 실행 시 전체 항목이 `번호. 명언` 형식으로 순서대로 출력되는지

```
[PASS] 인수 없이 실행하면 한 줄만 출력된다 (출력 1줄)
...
결과: 12 통과, 0 실패
```
