## 프롬프트

슬래시 커맨드 `/goal`로 실행했다.

```
/goal 내가 원하는 결과물과 많이 달라서 PRD를 변경했어. 다시 작업하자!
`docs/TASKS.md`의 모든 항목이 [x]로 바뀌고 `uv run pytest`가 종료 코드 0으로 끝난다.
TASKS.md가 없으면 `docs/PRD.md`를 기반으로 먼저 작성한다.
한 번에 하나의 TASK만 구현 (가장 중요)
막히면 그 항목에 'BLOCKED'를 적고 다음 항목으로 넘어간다.
같은 테스트 실패가 3번 반복되면 중단하고 실패 원인을 요약한다.
또는 20턴 후 중단한다.

모든 작업이 끝나면 `(프롬프트)`의 정책에 따라 정리할 것!
```

확장된 프롬프트: 위 조건을 세션 Stop 훅의 종료 조건으로 걸고, 조건이 만족될 때까지 멈추지 말고 작업하라는 지시가 붙는다.

### 실패와 대응
같은 테스트 실패가 3번 반복된 적은 없다. 실패는 모두 한 번 만에 고쳤다.
- **T10:** 테스트의 자식 카테고리 이름 "하위"가 화면 문구 "하위 1개"와 겹쳐 오탐했다. 테스트 이름을 바꿨다. 구현은 정상이었다.
- **T11:** 6건이 같은 원인으로 실패했다. 동기(`def`) 엔드포인트는 스레드풀에서 실행되어 `asyncio.get_running_loop()`가 없었다. 실제 버그였다. `CycleController`가 생성 시점의 이벤트 루프를 저장하고, 어느 스레드에서든 그 루프로 작업을 넘기도록 고쳤다.
- **T12:** 테스트 가정이 틀렸다. 하이라이트가 제목을 쪼개 원문 문자열이 그대로 보이지 않았고, `unicode61`은 단어 중간 검색이 안 된다. 동작이 아니라 테스트를 바꾸고, 한계를 README에 적었다.
- **자체 점검:** `or True`로 항상 통과하는 단언 3곳을 구체적인 단언으로 바꿨다. T6 토큰 가드 테스트도 10→5→3→0 순서를 실제로 관찰하도록 강화했다.

### 해석한 부분 (PRD가 모호했던 곳)
- **재시도 횟수:** "최대 3회, 2s→4s→8s"를 최초 시도 1번 + 재시도 3번(대기 3번)으로 해석했다.
- **병합된 카테고리:** 행을 삭제하지 않고 `merged_into_id`만 설정했다. LLM이 옛 이름을 다시 제안해도 대상으로 연결하기 위해서다.
- **병합 시 계층:** 2단계를 유지하도록 자식 재배치 규칙을 추가했다.
- **재구성 따라잡기:** 위키 재구성이 실패했을 때를 위해, 글 수와 `articles_count_at_rebuild`가 다른 카테고리를 다음 사이클에서 다시 만든다.
- **추가한 것:** `POST /fetch-now`(UI의 Fetch now 버튼, PRD에 문구만 있음), SQLite WAL 모드, 병합 직후 대상 카테고리의 백그라운드 재구성.

### 결과
- **목표 조건 충족:** TASKS.md 13개 항목이 모두 `[x]`이고, `uv run pytest`는 115개 통과, 종료 코드 0이다.
- **스모크 확인:** `/`, `/feeds`, `/categories/manage`, `/search`, `/logs`가 모두 200으로 응답하고, 스케줄러가 가동된다.
- **막힌 항목 없음:** `BLOCKED` 항목은 없다. 사용한 턴은 20턴 이내다.
- **만든 파일:** `pyproject.toml`, `.gitignore`, `README.md`, `docs/TASKS.md`, `src/rss_wiki/`(모듈·템플릿·프롬프트 38개 파일 중 소스), `tests/`
- **커밋:** 하지 않았다.

### 검증하지 못한 부분
- 실제 피드, 실제 `claude` CLI, 실제 trafilatura 다운로드로는 실행해 보지 않았다. 모두 가짜로 대체해 테스트했다. `claude -p` 출력 형식이 PRD의 가정(stdin 입력, 텍스트 출력)과 다르면 T3부터 영향을 받는다.
- 병합 UI의 되돌리기는 PRD 범위 밖이라 없다.
- 한국어 단어 중간 검색은 PRD가 정한 `unicode61` 때문에 안 된다.
- pytest 경고 1건(starlette TestClient의 httpx 지원 중단 안내)은 테스트 결과와 무관하다.
