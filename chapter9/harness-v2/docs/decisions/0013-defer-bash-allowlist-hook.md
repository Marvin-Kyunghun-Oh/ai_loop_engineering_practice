# 0013. Bash 허용 목록 훅은 스모크 테스트 뒤로 미룬다

- 상태: 확정
- 날짜: 2026-11-24

## 맥락
- 0008의 확인 결과, 허용 패턴만 주면 목록 밖의 **쓰기** 명령은 거부되지만 읽기 전용 명령(`whoami` 등)은 허용 목록과 무관하게 실행된다.
- 그래서 "허용한 명령만 실행된다"는 보장은 없다. 이를 막으려면 PreToolUse 훅으로 허용 패턴에 없는 Bash 명령을 거부해야 한다(STATUS "10단계에서 검토할 것").
- 이 훅은 C2의 위험 명령 차단 훅과 같은 종류라 10단계에서 함께 만들 수도 있었다.

## 결정
- Bash 허용 목록 훅은 10단계에서 만들지 않는다. **11단계 스모크 테스트 뒤**에 필요한지 다시 판단한다.
- 10단계는 `Bootstrap`과 위험 명령 차단 훅(C2)만 다룬다.

## 검토한 대안
- **10단계에서 함께 구현**: 한 번에 끝나지만, 훅 호출 조건과 `--settings` 전달 방식을 실제 claude로 확인해야 한다(haiku 1~2회, 약 $0.005). 쓰기 명령은 이미 막혀 있어 급하지 않다.

## 영향
- 당분간 generator·evaluator는 허용 목록 밖의 읽기 전용 명령을 실행할 수 있다. 파일을 바꾸는 명령은 계속 막힌다.
- 스모크 테스트의 `permission_denials`와 원본 로그를 보고, 읽기 전용 명령 때문에 실제 문제가 있었는지 근거를 모은 뒤 다시 정한다.
