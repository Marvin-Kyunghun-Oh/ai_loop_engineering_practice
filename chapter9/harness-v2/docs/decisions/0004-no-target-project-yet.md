# 0004. 첫 대상 프로젝트는 v2 범위에서 제외

- 상태: 확정
- 날짜: 2026-11-24

## 맥락
- v2를 검증하려면 언젠가 대상 프로젝트로 돌려야 한다. 후보로 TODO 앱(Java + Spring + Vue)이 나왔다.
- 사용자는 아직 무엇을 만들지 정하지 못했다.
- 지금의 목표는 하네스 자체를 이해할 수 있는 Java 코드로 개선하는 것이다.

## 결정
- 첫 대상 프로젝트는 v2 설계·구현 범위에서 제외한다.
- 대상 프로젝트에 종속되는 내용은 `harness.yml` 설정으로 분리해 하네스가 특정 프로젝트를 가정하지 않게 한다. 테스트 명령, 빌드 명령, 의존성 추가 방법, 허용 Bash 패턴이 여기에 해당한다(IMPROVEMENTS D3).

## 영향
- 대상 프로젝트를 정하면 그때 `harness.yml`과 PRD를 작성한다.
- 첫 실행은 작고 끝이 분명한 과제가 좋다. 그래야 v2의 사이클 수와 비용을 측정할 수 있다. 비용 보정 절차는 0007을 따른다.
