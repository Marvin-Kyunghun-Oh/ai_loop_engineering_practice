### M2. 오류 경로

### M3. 독스트링

### M4. 최종 검증 (parse_duration 범위)

### M5. 프리셋 저장 (PRD M2)
- PRD M2의 `save_presets`/`load_presets`와 테스트를 만든다. 이전 사이클에서 TASKS에 빠져 있던 요구다.

- 저장 전 검증, 파일 없음, 중복 이름을 테스트로 확인한다.
- 이 마일스톤이 끝나야 PRD 전체 대조(종료 판정)가 가능하다.

### M6. 시간 계산과 출력 (PRD M3)
- 사이클 13 대조에서 PRD M3가 PLAN/TASKS에 없는 간극으로 확인되어 추가했다.
- `total_minutes`(분 내림)는 합의와 무관하게 바로 착수한다.
- `format_duration`은 출력 형식 합의 A가 `docs/decisions/format-style.md`에 남아 있으므로 착수 가능하다(사이클 14). 형식은 `parse_duration`이 읽는 형식이다.
- 왕복 확인 값: 0, 59, 60, 3600, 5400, 86399.

## 자체 결정

- 파싱은 정규식 하나로 형식 전체를 검증한다. 앞뒤 공백은 `strip()`으로 먼저 제거한다. 빈 문자열은 정규식 검사 전에 따로 거른다. (되돌리기 쉬움)
- 검증 명령은 harness.yml 허용 목록(`python3 -m unittest`, `python3 -m compileall`)만 쓴다. `python3 -c`는 허용되지 않아 acceptance에서 뺀다. (되돌리기 쉬움)
- PRD M2(프리셋 저장)가 TASKS에 없던 간극이라 M5로 추가했다. 사이클 7. (되돌리기 쉬움)
- 프리셋 파일이 없으면 `load_presets`는 빈 dict를 돌려준다. 이름 중복은 파일을 읽을 때 `ValueError`로 막는다. (되돌리기 쉬움)
- 프리셋 CSV의 열 누락·빈 값 행도 `ValueError`로 통일한다. KeyError가 새지 않게 하기 위함이다. 사이클 12, T11. (되돌리기 쉬움)
- PRD M3 간극을 M6로 추가하고, `total_minutes`를 `format_duration`보다 먼저 두어 합의 대기 중에도 진행되게 했다. 사이클 13. (되돌리기 쉬움)
- 시간 출력 형식은 합의 A(`1h30m` 형식, 0초는 `0s`)로 확정했다. PRD M3에 반영. 사이클 14. (되돌리기 쉬움)
