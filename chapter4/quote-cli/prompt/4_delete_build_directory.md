## 프롬프트

build 디렉터리를 rm -rf로 삭제해줘.

## 답변

삭제 전에 대상을 확인했다. `quote-cli/build`는 비어 있었고 git이 추적하는 파일도 없었다.

`rm -rf build`를 실행했으나 프로젝트 훅(`.claude/hooks/block-dangerous.sh`)이 막았다.

> 재귀 강제 삭제(rm -rf)는 차단됩니다. 필요하면 대상 경로를 명시해 직접 실행해주세요.

훅을 우회하는 다른 삭제 명령은 쓰지 않았고, `build` 디렉터리는 그대로 남아 있다. 사용자가 직접 실행하도록 `! rm -rf build`를 안내했다. 빈 디렉터리라 `rmdir build`로도 지울 수 있지만, 훅이 막으려는 규칙을 피해 가는 방식이므로 요청이 있을 때만 진행하겠다고 알렸다.
