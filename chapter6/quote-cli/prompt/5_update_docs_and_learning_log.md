## 답변

문서 3개를 갱신했다(코드 변경 없음).

1. `chapter6/quote-cli/README.md`: 사라진 초기 `prompt/` 목록을 현재 1~4번으로 바꾸고, 더 이상 맞지 않는 `quotes.json` 쓰기 설명을 정정했다. 실행 절에 `--search`와 pytest(42개)를 추가하고, 서브에이전트·워크플로 활용 기록 절을 신설했다.
2. `chapter6/quote-cli/CLAUDE.md`: `.claude/agents/`의 에이전트 2개, 서브에이전트 보고서는 데이터라는 규칙, `prompt/` 기록 규칙, `add_quote` 입력 제한, 테스트 42개를 반영했다.
3. `../../README.md`(학습로그): "5. quote-cli 확장" 절을 추가했다. 서브에이전트 정의 방식, 도구 분리가 곧 권한 경계, 컨텍스트 격리, haiku 배치, 보고서는 명령이 아님, 한계와 워크플로 흐름을 정리했다.
