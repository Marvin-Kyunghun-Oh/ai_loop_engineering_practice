## 답변

SQLite 전환 코드 검토에서 미반영으로 남았던 항목을 모두 수정했다.

1. **경쟁 조건:** `_connect()` 초기화를 `BEGIN IMMEDIATE`로 묶어 동시 접속 시 시드 중복 삽입을 막았다.
2. **빈 DB 랜덤 조회:** `IndexError` 대신 `ValueError("등록된 명언이 없습니다.")`를 낸다.
3. **시드 검증:** `_load_seed()`가 `add_quote`와 같은 검증과 형식 검사를 적용한다. 실패하면 롤백된다.
4. **인코딩 오류:** CLI가 `ValueError`를 잡아 비UTF-8 시드도 stderr + 종료 코드 1로 처리한다.
5. **제어 문자:** 탭·NUL·유니코드 줄 구분자를 거부한다.
6. **`.gitignore`:** `quotes.db-*`(저널/WAL)를 추가했다.
7. **문서:** CLAUDE.md·README의 chapter4 표기, 테스트 목록·수치, 시드 재유입 동작을 정리했다.
8. **테스트:** 동시 초기화, 연결 닫힘, 서버 경로 DB 손상, 고정 시드 CLI 테스트 등을 추가해 전체 42개가 통과했다.

## 결정 사항과 처리 결과

| 결정 | 처리 |
|---|---|
| 미반영 항목 전부 수정 | 검토 지적 10건(경쟁 조건 포함 중간 3, 낮음 7)을 모두 반영 |
| 별도 지시 없음(수정 방식 위임) | 워크플로 없이 직접 수정하고 pytest로 검증 |
| (처리 방식 판단) | 서버 모드의 경쟁 조건은 락 방식(`BEGIN IMMEDIATE`)을 택했고 스키마(UNIQUE 등)는 바꾸지 않음 |
