## 프롬프트

main.py에 --search<키워드> 옵션을 추가해줘. 명언 본문에 키워드가 포함된 항목만 출력되어야 해. 구현이 끝나면 코드 검토와 테스트 검증까지 진행해줘. 모든 작업이 끝나면 (프롬프트)의 정책에 따라 요약정리해줘.

## 답변

작업 순서 요약:

1. `main.py` 확인 후 `search_quotes(keyword)` 헬퍼와 `argparse` 기반 `--search` 옵션을 추가했다. 옵션이 있으면 본문 일치 항목만 출력하고 종료, 없으면 기존 MCP 서버 실행.
2. 수동 실행으로 일치/빈 키워드(종료 코드 2)/결과 없음을 확인했다.
3. `tests/test_search.py`를 작성했다.
4. `code-reviewer`와 `test-runner` 서브 에이전트를 병렬 실행했다. 테스트는 6개 통과.
5. 검토 지적 중 공백 키워드 처리 불일치, 실제 데이터 의존 테스트, 인코딩 환경 변수, `casefold`를 반영했고 테스트 7개가 통과했다.
6. README에 작업 기록을 추가했다.

7. 미반영이던 두 항목을 사용자 승인 후 진행했다: `--search`의 quotes.json 오류(없음/깨진 JSON/키 누락)를 stderr 메시지 + 종료 코드 1로 처리하고 테스트 3개 추가(총 10개 통과), CLAUDE.md의 테스트 문구·명령어·`--search` 분기 설명을 갱신했다.
