# llmops_lab 코드 작성 지침

## 주석 규칙 (한국어)

- **파일 상단**: 파일의 목적과 핵심 기능을 2줄 이하로 요약한다. 처리 절차가 있으면 `A → B → C` 형태로 함께 적는다.
- **클래스/함수**: docstring으로 "무엇을 위한 것인지"와 핵심 기능만 2줄 이하로 적는다. 절차가 있으면 같이 적고, 장황한 설명은 하지 않는다.
- **주의사항**은 짧게 명시한다 (예: 템플릿은 `str.format()` 방식이라 `{name}` 단일 중괄호만 치환된다).
- **상수/설정값**에는 의미와 제약(예: 상대 경로라 프로젝트 루트에서 실행)을 한 줄로 적는다.

## 테스트 규칙

- 테스트 함수명은 **한글**로 작성한다. 예: `test_필수_키워드가_없어도_프롬프트가_렌더링된다`
- 각 테스트 첫머리에 "무엇을 넣고 무엇을 확인하는지"를 한 줄 주석으로 적는다.
- 테스트 파일 상단에 검증 대상 모듈과 목적을 한 줄로 적는다.
